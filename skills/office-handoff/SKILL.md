---
name: office-handoff
description: Preserve task continuity when a Fourteenth agent stops, changes models, or hands work to another office worker. Use for agent replacement and task-dependent collaboration.
---

Write a compact handoff containing the original objective, current status, file paths touched, decisions with evidence, verification results, unresolved blockers, and the next useful action. Separate completed actions from proposed actions. Do not include credentials or hidden reasoning.

Before replacement, interrupt the active turn and await its completion acknowledgement. Preserve the previous task's history. A replacement begins from the observable handoff and must inspect the real workspace because an interrupted operation may be partially applied.

For a manager replacement, pause its workers before transferring ownership. Resume coordination explicitly; never allow two managers to write concurrently. An ejected avatar represents a stopped task, not deleted files or erased history.

Send context only to the worker that needs it. Prefer a concrete request and a file reference to a full transcript. If the receiver is active, steer the current task; if idle, start a follow-up. Keep handoffs within the office unless the user authorizes an external recipient.
