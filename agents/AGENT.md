# Iteration1 office

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Iteration1 is an office where coding agents (Codex, Claude, Cursor) work on one project, each at a visible desk. This agent lets the office's owner check on it and start work from ASI:One.

- **status**: tasks, blockers and who is working
- **report on <task>**: what was done, and which receipts the office verified versus ones an agent only reported
- **approvals**: commands waiting for the owner in the office
- **alerts**: what its companion watcher agent noticed: tasks that blocked, finished or need review, and new approval requests
- **mission: <what to build>**: hand a new mission to the office's implementation manager, after a confirmation step

The office runs on its owner's computer and the agent connects through its Agentverse mailbox. Only addresses paired with a code shown in the owner's terminal can use it. Command approvals and stopping agents stay in the office app.
