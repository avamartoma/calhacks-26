# Iteration1 reviewer

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

The reviewer checks finished work from an Iteration1 office of coding agents. When a task reaches review, or when the owner asks **iteration1-office** to review one, it reads the task's run doc and judges each acceptance criterion against the receipts: met, unproven or contradicted, citing the receipts it relied on. It treats claims an agent reported about itself as weaker than evidence the office observed.

It only reads. Approving, editing and marking work verified stay with the owner in the office app. It runs on the owner's computer and answers through iteration1-office.
