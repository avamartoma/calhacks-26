# Project workbench starter

This is the starting point for a real Fourteenth feature run, not a completed search demo.

Copy this folder to a separate local workspace, run `npm install`, initialize Git and commit the starter. Use `npm run dev` for the preview at http://127.0.0.1:4320. `npm test` and `npm run build` verify it.

Suggested task: Add instant case-insensitive search over project names and descriptions, an Active/All filter, saved filter preferences, an accessible result count, and a clear-search action that returns focus to the search input. Preserve the simple design. Add regression tests and request independent review.

Store generated screenshots under `artifacts/` so they do not change the source fingerprint. Do not commit dependencies or browser artifacts.
